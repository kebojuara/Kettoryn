# Kettoryn screenshots

Seven real Android captures, in dark theme and portrait orientation. Each JPEG is 1220×2544 pixels. The same system-bar crop was applied to all seven 1220×2712 originals, without resizing, recoloring or changing the application UI.

| Filename | Screen |
|---|---|
| `home.jpg` | Home dashboard |
| `routines.jpg` | Routine creation and saved routines |
| `exercises.jpg` | Offline exercise library |
| `history.jpg` | Workout history |
| `progress.jpg` | Training progress |
| `workout-share.jpg` | Summary sharing preview |
| `settings.jpg` | Appearance, units, rest timer and backups |

The Home, Routines, History and Progress captures show their initial empty states. The sharing capture shows a completed session. Screenshots show the visible viewport rather than an entire scrolling page.
